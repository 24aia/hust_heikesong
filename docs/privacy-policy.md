# 隐私说明

最后更新：2026-09-15

刘看山长文续读助手在 Firefox 本地保存阅读位置、手动书签、扩展设置和回顾缓存。开发者不会通过自有服务器收集这些本地数据，也不使用分析、广告或跨站跟踪服务。

用户进入回顾面板并主动点击“开始回顾”或“重新生成”时，扩展会把页面标题以及用户所选断点之前的知乎正文发送至知乎直答 API（`https://developer.zhihu.com/v1/chat/completions`），用于生成本次回顾。回顾请求不会发送断点段落及其后的正文。

用户主动打开“解释词句”、选中文字并点击“开始解释”时，扩展会向同一 API 发送所选词句及附近原文。选中文字最多 1,000 个 UTF-16 代码单元，附近原文最多 2,000 个；点击“发送追问”会同时发送当前会话的相关消息。词句解释与回顾的范围独立，词句可以来自断点之后，但不会因此进入回顾请求。普通选择文字不会弹出入口或发起模型请求。解释对话仅保留在当前面板内存中，退出解释面板后丢弃，不写入本地缓存。停止等待或关闭界面会忽略迟到结果，但已经发送的模型请求仍可能完成。

扩展不会发送知乎登录 Cookie、账号密码或浏览器存储导出。

生成结果与阅读断点保存在本地。用户可以通过扩展中的“清除本地数据”删除本地记录，也可以在 Firefox 扩展权限设置中撤销相关权限或卸载扩展。

发布版可能内置一个仅用于调用知乎直答 API 的共享访问凭据。该凭据不用于识别扩展用户。知乎直答 API 对所接收数据的处理同时受知乎相关服务条款与隐私规则约束。
