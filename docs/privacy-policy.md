# 隐私说明

最后更新：2026-09-14

刘看山长文续读助手在 Firefox 本地保存阅读位置、手动书签、扩展设置和回顾缓存。开发者不会通过自有服务器收集这些本地数据，也不使用分析、广告或跨站跟踪服务。

当且仅当用户主动点击“回顾到这里”或“回顾后继续”时，扩展会把页面标题以及用户所选断点之前的知乎正文发送至知乎直答 API（`https://developer.zhihu.com/v1/chat/completions`），用于生成本次回顾。断点段落及其后的正文不会发送。扩展不会发送知乎登录 Cookie、账号密码或浏览器存储导出。

生成结果与阅读断点保存在本地。用户可以通过扩展中的“清除本地数据”删除本地记录，也可以在 Firefox 扩展权限设置中撤销相关权限或卸载扩展。

发布版可能内置一个仅用于调用知乎直答 API 的共享访问凭据。该凭据不用于识别扩展用户。知乎直答 API 对所接收数据的处理同时受知乎相关服务条款与隐私规则约束。
